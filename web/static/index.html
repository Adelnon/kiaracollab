Commands

Two slash commands. The first does almost everything.

/task <request> core

Describe anything you want done and Claude figures out the sequence of Discord actions to carry it out, then reports back a plain-English summary of what it did.

  • /task ban @spammer for raiding and delete their last day of messages
  • /task time out @loud-user for 30 minutes
  • /task give @newbie the Member role and welcome them in #general
  • /task rename #general to #lobby and set its topic to "hang out here"
  • /task set this server up like a community — welcome, rules, general, voice, mod-only
/uptime utility

Show how long the bot has been running.

Safety first

Powerful moderation tools need guard rails. Kiara ships with them on.

Access is gated

/task only runs for allow-listed user IDs, or — if no list is set — for members with the guild Administrator permission.

Never exceeds its permissions

A ban without Ban Members comes back as forbidden, not a crash. The bot can only do what Discord already lets it do.

Turn cap per request

Each /task is bounded by a configurable maximum number of agent turns, so a request can't spiral out of control.

Transparent actions

Every reply lists exactly what the bot did, so there's an audit trail of each ban, kick, timeout and change.

Get started

Self-host in a few minutes.

  1. Create a Discord application and bot, enabling the Server Members and Message Content intents.
  2. Invite the bot with the bot and applications.commands scopes and the moderation permissions (Manage Channels/Roles, Kick, Ban, Moderate Members, Send/Manage Messages).
  3. Copy .env.example to .env and fill in your Discord token and Anthropic API key.
  4. Run python bot.py — set WEB_ENABLED=true to serve this page with live status. 
cp .env.example .env
# edit .env — set DISCORD_TOKEN, ANTHROPIC_API_KEY, WEB_ENABLED=true
pip install -r requirements.txt
python bot.py
